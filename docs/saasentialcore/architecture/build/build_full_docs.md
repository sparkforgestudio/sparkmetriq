# Executive Summary

Ce package regroupe l’ensemble des contrats normatifs **DOC-SC-001 → DOC-SC-024** définissant
le socle SaasentialCore : architecture, fiabilité (SRE++), sécurité, multi-tenant, gouvernance IA,
contrôle des coûts (FinOps) et auditabilité enterprise.

## Objectifs
- Standardiser l’architecture et l’exécution (DI, workers, gateway, retries, state machines).
- Garantir l’isolation multi-startup / multi-tenant.
- Assurer l’observabilité, la résilience et la capacité de reprise.
- Gouverner l’IA (registry, policies, budgets) et maîtriser les coûts.
- Être prêt pour audits externes (SOC2/ISO mindset).

## Principe clé
La **documentation (Markdown)** est la *source of truth*.  
Les **PDF** sont des artefacts dérivés, générés et versionnés.
